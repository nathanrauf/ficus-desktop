# Ficus for macOS

Not built yet. This will bring the same OS-level social media blocking to macOS, pairing with the Windows version in [../windows/](../windows/) and the Ficus iOS app.

Likely approach: entries in `/etc/hosts` (the macOS equivalent of the Windows hosts file), plus a small menu bar app in place of the WinForms GUI, since macOS doesn't have anything directly equivalent to that.
